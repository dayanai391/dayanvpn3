# DayanVPN Panel — پنل فروش VPN با ربات تلگرام

سیستم کامل: ربات تلگرام ادمین، مشتری‌سازی خودکار (UUID + لینک اختصاصی)، شمارش مصرف واقعی بایت‌به‌بایت، قطع خودکار وقتی حجم یا تاریخ تموم شد.

## چیکار می‌کنه

- `/new نام گیگ روز` → مشتری جدید با UUID مخصوص، لینک ساب اختصاصی (`.../sub/کد`)
- هر مشتری **مسیر و پورت مخصوص خودش** رو داره → مصرف واقعی‌اش شمرده میشه
- حجم تموم یا تاریخ گذشته → **خودکار قطع** (حتی لینک سابش هم 403 میده)
- `/list` مصرف و باقی‌مانده رو نشون میده · `/topup` شارژ · `/del` حذف
- اطلاعات مشتری‌ها توی یه **Gist مخفی گیت‌هاب** ذخیره میشه (با آپدیت سرور از بین نمیره)

## راه‌اندازی

### ۱. ربات تلگرام
1. توی تلگرام به **@BotFather** پیام بده → `/newbot` → اسم و یوزرنیم بساز
2. **توکن** رو کپی کن (چیزی مثل `123456:ABC-DEF...`)
3. به **@userinfobot** پیام بده تا **آیدی عددی خودت** رو بده

### ۲. ریپو و ریلوی
1. یه ریپوی خصوصی جدید توی گیت‌هاب بساز (مثلاً `dayanvpn-panel`) و هر ۵ فایل رو آپلود کن
2. ریلوی → New Project → Deploy from GitHub repo
3. Networking → Generate Domain

### ۳. متغیرها (توی تب Variables سرویس)

| متغیر | مثال | توضیح |
|---|---|---|
| `BOT_TOKEN` | `12345:ABC...` | توکن ربات از BotFather |
| `ADMIN_IDS` | `123456789` | آیدی عددی خودت (کاما برای چند ادمین) |
| `SERVERS` | `yourdomain.up.railway.app` | دامنه(ها)ی سرور، با کاما جدا، فرمت `domain:TAG` |

ذخیره کن → ریلوی دوباره بیلد میکنه.

### ۴. بکاپ (اختیاری ولی توصیه‌شده)
بدون بکاپ، با هر آپدیت سرور لیست مشتری‌ها پاک میشه:
1. از یه اکانت گیت‌هاب (میشه همون اکانت) یه **Personal Access Token** با دسترسی **gist** بساز: GitHub → Settings → Developer settings → Fine-grained tokens → فقط scopes: Gist
2. متغیر `GITHUB_TOKEN` رو اضافه کن
3. سرور رو یه بار Restart کن → ربات خودش یه Gist میسازه و **آیدیش رو توی لاگ** چاپ میکنه
4. آیدی Gist رو کپی کن → متغیر `GIST_ID` رو اضافه کن → باز Restart

## دستورات ربات

```
/new reza 10 30     ← مشتری: رضا، ۱۰ گیگ، ۳۰ روز
/list               ← لیست + مصرف واقعی + روز باقی‌مانده
/topup reza-code 5 15   ← شارژ ۵ گیگ و ۱۵ روز
/del کد             ← حذف کامل مشتری
/backup             ← بکاپ دستی
```

## نحوهٔ فروش به مشتری
1. مشتری پول رو کارت‌به‌کارت میزنه
2. تو `/new` میزنی
3. لینکی که ربات میده رو براش میفرستی
4. مشتری: v2rayNG → منو → Online Subscription → لینک رو paste → Update

## نکات مهم
- **مصرف شمارش‌شده از لاگ nginx میاد** — بعد از هر آپدیت سرور، شمارنده‌ها از Gist برمی‌گردن
- اگه `SERVERS` چند دامنه داشته باشه، هر لینک ساب همهٔ سرورها رو داره
- قطعی خودکار: وقتی حجم تموم بشه، هم کانفیگ از سرور میره هم `/sub` و `/u/` اون مشتری 403 میده
- برای اضافه کردن سرور دوم (اروپا و ...): همون ریپو رو به‌عنوان سرویس دوم deploy کن و `SERVERS` رو روی هر دو با مقدار کامل ست کن
